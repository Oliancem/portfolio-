## Publier sur GitHub Pages

1. Dépose tous les fichiers de ce dossier à la racine du dépôt.
2. Dans **Settings > Pages**, choisis la branche `main` et le dossier `/ (root)`.
3. Le site est disponible après une minute sur `https://oliancem.github.io/<nom-du-depot>/`.
